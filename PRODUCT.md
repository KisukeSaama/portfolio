# Product

## Register

brand

## Users

The portfolio speaks to recruiters, technical leads and hiring managers assessing a junior Java
profile for a 14-month apprenticeship starting September 2026. A recruiter needs the contract terms
in ten seconds. A technical lead needs to see decisions, not a technology list. Both need to know
what Jonathan cannot do yet.

## Product purpose

Present Jonathan Blanchard as a Java and Spring Boot developer who ships and operates what he ships.
The narrative is carried by a deliberate career change, decisions he would defend in review, and an
honest statement of the experience he lacks. Janus and Episort are the proof; Overkill and the mini
social network show team and learning work. Next.js publishes that narrative as one self-contained
site whose content is versioned alongside the code.

## Languages

The public site ships in English and French. Interface copy lives in the two dictionaries. Each case
study has matching English and French JSON content, keyed by the same stable slug.

## Brand personality

Warm, methodical, direct. The interface evokes a well-kept digital workbench: precise tools, visible
choices and frank orange energy, with no gratuitous spectacle. The voice stays natural, confident
without claiming expertise, and honest about the state of each project.

## Anti-references

Not a SaaS landing page, not a Bento-grid portfolio, not a fake terminal. Excluded: text gradients,
glassmorphism, glows, invented statistics, rows of technology logos, repetitive cards, affected
editorializing, permanent animation and artificial marketing.

## Design principles

1. Present the person before the proof.
2. Show the product reasoning: problem, decisions, trade-offs, result.
3. Convey command without overplaying it: honest statuses, no invented facts.
4. Give every color accent, movement and icon a function.
5. Keep content changes reviewable in the same history as the interface.

## Accessibility and inclusion

Target WCAG 2.2 AA: verified contrast, keyboard navigation, visible focus, semantic HTML, adequate
touch targets, text alternatives and full operation under `prefers-reduced-motion`. No state depends
on color or hover alone.
